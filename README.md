# Connectivity

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_470193_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/470193.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Connectivity is a lightweight minecraft mod which solves several connection problems like Login-Timeouts, DecoderException, Packet size limits, Ghostblock issues, Payload too large
and more. It also offers commands to analyze network traffic and a bunch of debugging utilities, advanced error logging, packet logging etc.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
